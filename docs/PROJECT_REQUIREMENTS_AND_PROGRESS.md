交付方式：个人设备 Xcode 直装，代码持续同步 GitHub `master`

## 1. 产品目标

在 2026-08-23 前提供一个轻量、无自建服务器、可安装到个人 iPhone 的科目三路线训练工具。训练前完成路线采集和两类点编辑，训练中使用地图、语音与震动低干扰提醒，训练后查看完成、易错和跳过节点。

安全边界：本应用是记忆和训练辅助工具，不能代替道路观察、教练指令、考试规则或正式导航。驾驶员行驶中不得编辑路线或输入文字。

## 4. 本轮补齐的缺失功能

2026-08-20 根据需求与代码对照，补齐以下闭环：

1. 路线录制实时显示有效时长和 GPS 精度。
2. 路线详情显示完整轨迹和考试节点地图。
3. 训练页增加暂停、继续、暂停后结束和跳过节点。
4. 训练记录增加详情页，列出完成、易错和跳过的具体节点。
5. 增加暂停/恢复/跳过结果持久化、导入轨迹保留节点两项自动化集成测试。
6. 增加独立的模拟考试考核项目播报系统，避免训练口诀与考试指令混播。
7. 增加路线详情地图选点，允许在 Apple 地图导入轨迹后补充两类训练内容。

### 模拟考试考核播报详细定义

训练提示点与考核播报点是两类不同数据：

| 对比项 | 训练提示点 | 考核播报点 |
|---|---|---|
| 目的 | 帮助记忆操作和易错点 | 模拟考试车载语音系统 |
| 语音内容 | 用户编辑的口诀/提示 | 系统预设的标准考核项目文本 |
| 推进方式 | 用户标记完成、有困难或跳过 | 进入触发范围后自动播报并自动推进 |
| 训练结果 | 保存节点结果 | 不产生完成/易错结果，只记录训练轨迹 |
| 地图样式 | 普通编号标记 | 橙色扬声器标记 |

预设考核项目包括：起步、直线行驶、变更车道、路口左转、路口右转、通过路口、通过人行横道、通过学校区域、通过公共汽车站、会车、超车、掉头和靠边停车。

模拟考试模式的音频白名单仅包含所触发项目的 `announcementText`。开始训练、暂停、继续、下一训练点和操作口诀均不进入语音合成器，从而满足“只播报考核项目”。
