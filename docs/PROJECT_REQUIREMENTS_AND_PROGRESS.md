# 驾考路线智能训练 APP：需求与进度总览

更新时间：2026-08-20  
目标平台：iPhone（主应用）+ Apple Watch（辅助提醒）  
交付方式：个人设备 Xcode 直装，代码持续同步 GitHub `master`

## 1. 产品目标

在两周 MVP 周期内提供一个轻量、无自建服务器、可安装到个人 iPhone 的科目三路线训练工具。训练前完成路线采集和节点编辑，训练中使用地图、语音与震动低干扰提醒，训练后查看完成、易错和跳过节点。

安全边界：本应用是记忆和训练辅助工具，不能代替道路观察、教练指令、考试规则或正式导航。驾驶员行驶中不得编辑路线或输入文字。

## 4. 本轮补齐的缺失功能

2026-08-20 根据需求与代码对照，补齐以下闭环：

1. 路线录制实时显示有效时长和 GPS 精度。
2. 路线详情显示完整轨迹和考试节点地图。
3. 训练页增加暂停、继续、暂停后结束和跳过节点。
4. 训练记录增加详情页，列出完成、易错和跳过的具体节点。
5. 增加暂停/恢复/跳过结果持久化、导入轨迹保留节点两项自动化集成测试。
