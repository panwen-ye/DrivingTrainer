# 驾考训练 MVP 集成测试用例

## 测试范围

- iPhone 首次启动、导航与本地数据初始化。
- 定位授权、路线录制、暂停/继续、节点标记和保存。
- 路线节点编辑、删除、版本更新与持久化。
- 训练节点顺序、距离提醒、人工结果标记和训练结束。
- 训练记录排序、易错节点统计与重新启动后的数据恢复。
- Apple Watch 未配对时的安全降级，以及配对后的摘要与震动链路。
- iPhone/watchOS 工程构建、打包与模拟器安装。

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| IT-A01 | 路线到训练记录闭环 | 保存含轨迹和两节点的路线，重载后完成一次训练，再保存并重载记录 | 路线完全一致；按顺序触发两个提醒；轨迹、完成/困难结果及备注完整保留 |
| IT-A02 | 路线编辑幂等更新 | 保存路线后增加节点和版本，再次 upsert | 仍只有一条同 ID 路线，版本与节点均更新 |
| IT-A03 | 多次训练排序 | 乱序保存新旧两次训练 | 重载后始终按开始时间倒序排列 |
| IT-A04 | 核心回归 | 运行 Domain、Persistence 全部单元测试 | GPS 过滤、距离、提醒冷却、状态机和原子存储全部通过 |

| IT-A06 | 暂停/恢复/跳过闭环 | 暂停时发送定位点，再恢复并跳过、完成节点，保存重载记录 | 暂停期间不采集；跳过与完成结果、备注和结束时间完整持久化 |
| IT-A07 | Apple 导入更新语义 | 为已有节点路线写入导入轨迹并递增版本 | 轨迹更新、版本递增，原考试节点不丢失 |

## 模拟器端到端用例

| 编号 | 场景 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| IT-U01 | 首次启动 | 清洁安装 | 启动 App | 显示安全提示与 1/3/4 号路线，无崩溃和数据错误弹窗 |
| IT-U02 | 定位授权 | 首次进入地图 | 打开训练准备页，选择“使用 App 时允许” | 权限说明准确，地图与定位控件正常显示 |
| IT-U03 | 空路线训练保护 | 初始路线无节点 | 打开 1 号线训练准备页 | 显示 0 个节点，“开始训练”不可用 |
| IT-U04 | 进入路线录制 | 已允许定位 | 路线页点击“录制” | 显示名称、距离、轨迹点、节点和开始录制按钮 |
| IT-U05 | 录制状态转换 | 位置信号可用 | 开始录制，暂停，再继续 | 状态按钮正确变化；暂停期间不采集点；继续后恢复 |
| IT-U06 | 标记考试节点 | 录制中且有最新位置 | 点击“标记考试节点” | 打开节点编辑表单，默认口令与 120 米半径正确 |
| IT-U07 | 编辑并保存节点 | 节点编辑表单已打开 | 选择类型、修改口令/距离并保存 | 节点计数增加，路线保存后可在详情中再次编辑 |
| IT-U08 | 结束并保存路线 | 已有有效轨迹 | 点击“结束并保存” | 返回路线列表，新路线及节点数可见；重启后仍存在 |
| IT-U09 | 训练提醒 | 路线含节点 | 开始训练并模拟进入节点半径 | 中文语音提醒和手机震动触发，Watch 不可达不导致崩溃 |
| IT-U10 | 训练复盘 | 训练中标记“完成/有困难”并结束 | 打开记录页 | 产生一条记录，轨迹点和易错数量正确 |
| IT-U11 | Watch 配对元数据 | 构建并安装含 Watch App 的 iPhone 包 | 安装到模拟器/真机 | Watch 包含正确的 companion bundle identifier，安装不再失败 |
| IT-U12 | 未配对降级 | 模拟器无配对 Watch | 启动并操作训练 | 控制台仅报告未配对，iPhone 主流程持续可用 |
| IT-U13 | 地图缩放 | 打开录制或训练地图 | 双指缩放；分别点击“放大地图”和“缩小地图” | 三种操作均可改变地图视野，比例尺同步变化，按钮有中文辅助功能标签 |
| IT-U14 | 路线初始视野 | 路线含轨迹或节点 | 打开训练准备页 | 初始视野框选全部轨迹和节点并保留边距；空路线回退到当前位置 |
| IT-U15 | Apple 地图链接导入 | Apple 地图分享的驾驶路线链接 | 选择目标考试路线、粘贴链接并导入 | 解析起终点并生成 Apple 驾驶轨迹；目标路线版本递增、原考试节点保留 |
| IT-U16 | 导入错误保护 | 非 Apple 链接、地点链接或缺少起终点 | 尝试导入 | 不修改本地路线，显示可操作的中文错误信息 |
| IT-U17 | Apple 风格缩放控件 | 打开录制或训练地图 | 观察位置；点击、长按加减按钮 | 控件以紧凑纵向浮层固定在右下角，不遮挡路线；单击按一级平滑缩放，长按连续缩放 |
| IT-U18 | 鼠标滚轮缩放 | iPhone/iPad 连接鼠标或在 Mac 兼容环境运行 | 指针位于地图上，滚轮向上和向下滚动 | 向上放大、向下缩小；不影响触摸拖动与双指缩放 |
| IT-U19 | 录制指标 | 进入路线录制页 | 开始、等待、暂停、继续 | 距离、有效时长、GPS 精度、轨迹点和节点数显示；暂停时间不计入有效时长 |
| IT-U20 | 路线详情地图 | 已保存含轨迹/节点路线 | 从路线列表打开详情 | 地图自动框选轨迹和节点，节点列表仍可编辑删除 |
| IT-U21 | 训练暂停与结束 | 训练进行中 | 暂停，观察标题，再继续或直接结束 | 标题显示“训练已暂停”；暂停不采点；继续恢复；暂停状态可安全结束 |
| IT-U22 | 跳过节点 | 路线含至少一个节点 | 开始训练并点击“跳过” | 当前节点记录为 skipped，进入下一节点，结束后复盘可见 |
| IT-U23 | 训练复盘详情 | 已完成包含完成/易错/跳过结果的训练 | 打开记录并进入详情 | 显示路线、开始时间、时长、轨迹点、三类计数和每个节点结果 |

## 通过规则

- IT-A01 至 IT-A07、IT-U01 至 IT-U23 必须全部通过，才视为基础 MVP 软件验收通过。
- IT-D01 至 IT-D04 需要真实设备与用户授权；未执行时必须明确标记为“待真机”。
- 不允许存在导致崩溃、路线数据丢失、错误节点顺序或无法安装的高优先级缺陷。
