# 两周 MVP 开发计划

目标：从正式编码日 T0 起，在 10 个工作日内产出可通过 Xcode 安装到个人 iPhone 的轻量 MVP；第 11–14 天作为真机缓冲、实地校准和修复窗口。TestFlight、App Store、云同步和完整 Watch 操作不阻塞交付。

## MVP 成功标准

- iPhone 可安装、启动并离线使用。
- 可查看同心考场 1、3、4 号路线及节点。
- 可录制 GPS 轨迹并快速标记节点。
- 训练时能根据距离播报下一节点。
- 可保存一次训练并标记易错点。
- Watch 能显示下一节点摘要并震动；Watch 不可用时手机功能完整。

## 第 1 周：形成手机端闭环

### Day 1：工程与真机安装

创建 iOS/watchOS 工程、签名、最小模块和测试 target；当天完成 iPhone 空壳安装。

验收：真机启动；拒绝权限不崩溃；Agent 可重复执行构建与测试。

### Day 2：模型与种子路线

完成 Route、RouteNode、PracticeSession、TrackPoint 和 Codable JSON Store；准备 1、3、4 号线种子数据格式。

验收：数据导入、保存、重启读取均通过测试。

### Day 3：路线浏览

完成三入口导航、路线列表、路线详情、MapKit 轨迹和节点展示。

验收：三条路线离线可查看，地图交互流畅。

### Day 4：定位与录制

完成权限引导、定位状态、轨迹采样、精度过滤和开始/暂停/结束。

验收：室外步行录制 20 分钟无明显拉飞和数据丢失。

### Day 5：节点编辑

完成当前位置标记、节点类型、口诀、顺序和提醒距离的精简编辑。

验收：录制中可单击标记，停车后可补充并持久化。

## 第 2 周：训练、复盘与 Watch

### Day 6：提醒状态机

完成路线进度、下一节点、进入半径、去重、跳过和错向保护。

验收：单元测试覆盖接近、离开、重复进入和定位漂移。

### Day 7：训练模式

完成大字号训练页、语音提醒、完成/易错标记和训练结束流程。

验收：GPX 回放可完整走通一条路线，提醒顺序正确。

### Day 8：训练记录

完成本次报告、易错节点列表和最近训练记录；不做复杂图表。

验收：训练退出或异常中断后，已完成记录可恢复或安全结束。

### Day 9：Watch 轻量端

完成下一节点摘要同步、提醒震动和断连降级。

验收：Watch 断连不影响手机；连接时摘要和震动正常。

### Day 10：发布候选版

完成权限文案、空状态、错误提示、性能检查、隐私检查和 Release 构建。

验收：全新安装后可从选择路线走到训练报告；生成可重复安装的 Release 版本。

## Day 11–14：真机缓冲与校准

- 步行测试后再进行副驾驶或教练陪同实地验证。
- 校准节点半径、定位精度阈值、播报节奏和震动类型。
- 只修复影响安装、数据安全、提醒正确性和驾驶安全的问题。
- 最迟第 14 天冻结 MVP，并保留已知限制清单。

## Agent 执行规则

- 一个 Agent 任务只对应一个可验收功能，避免超大改动。
- 每天结束必须保持主分支可构建、可安装。
- Agent 生成的数据模型、定位逻辑和权限配置必须由测试或真机证据验证。
- 不因“以后可能需要”引入包、协议层、服务器或复杂抽象。
- 任何范围新增都先与后续迭代交换，不能挤占当天关键路径。

## 两周后迭代队列

1. 更可靠的后台定位与中断恢复。
2. Watch 开始/暂停、快捷标记及独立记录。
3. CloudKit 备份与多设备同步。
4. 照片、音频笔记和路线包导入导出。
5. 更丰富的复盘统计和个性化复习。
6. 有足够真实数据后再评估 AI 分析，始终不进入实时安全提醒链路。

## 主要风险与降级方案

| 风险 | 两周内降级方案 |
|---|---|
| 路线坐标未准备好 | 先用手工种子或 GPX，保留现场录制校准 |
| 后台定位不稳定 | MVP 要求训练时保持前台；后续补强 |
| Watch 调试耗时 | 手机先交付；Watch 仅保留摘要和震动 |
| 免费签名限制 | 先 Xcode 直装；付费账号和 TestFlight 后置 |
| GPS 漂移导致误提醒 | 增大冷却并允许手动完成或跳过节点 |

## 开工前只需确认

- [ ] iPhone/iOS、Watch/watchOS、Mac/Xcode 版本。
- [ ] Apple ID 已能在 Xcode 登录并完成真机签名。
- [ ] 1、3、4 号线至少有可录入的节点顺序与大致坐标。
- [ ] 两周交付只面向个人 iPhone，不要求 App Store 上架。
