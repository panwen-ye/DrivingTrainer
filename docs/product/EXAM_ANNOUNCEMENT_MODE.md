# 模拟考试考核项目播报设计

## 1. 目标

训练模式增加“模拟考试播报”：车辆按路线行驶并进入预设考核项目范围时，系统按顺序自动播报对应考试口令。该模式模拟考车语音，帮助使用者练习听到项目后的操作反应。

最重要的约束是：**模拟考试模式只播报考核项目口令**。它不播报训练口诀、环境说明、开始/暂停/继续/结束状态，也不把普通地图标记点当作考核项目。

## 2. 与训练提示点的边界

| 对比项 | 训练提示点 `RouteNode` | 考核项目播报点 `ExamAnnouncement` |
| --- | --- | --- |
| 用途 | 教学、纠错和记忆路线 | 模拟考车下达考试指令 |
| 内容 | 标题、操作口诀、困难标记等自由内容 | 受控的预设考核项目和固定播报口令 |
| 触发引擎 | `ReminderEngine` | `ExamAnnouncementEngine` |
| 地图样式 | 普通训练节点标记 | 橙色扬声器标记 |
| 播报模式 | 训练提示模式 | 模拟考试播报模式 |
| 进度 | 可完成、有困难或跳过 | 进入范围即自动推进，不要求触屏确认 |
| 存储 | `Route.nodes` | `Route.announcements` |

两类数据可以位于相同坐标，但仍是两个独立对象。新增、编辑、删除、排序和触发其中一类，不得隐式改变另一类。

## 3. 预设项目与口令

MVP 使用受控枚举，避免用户输入任意文字后破坏“只播考核项目”的规则：

| 考核项目 | 播报口令 |
| --- | --- |
| 起步 | 开始起步 |
| 直线行驶 | 开始直线行驶 |
| 变更车道 | 开始变更车道 |
| 左转弯 | 前方路口左转 |
| 右转弯 | 前方路口右转 |
| 通过路口 | 前方通过路口 |
| 通过人行横道 | 前方通过人行横道 |
| 通过学校区域 | 前方通过学校区域 |
| 通过公共汽车站 | 前方通过公共汽车站 |
| 会车 | 开始会车 |
| 超车 | 开始超车 |
| 掉头 | 前方请选择合适地点掉头 |
| 靠边停车 | 请靠边停车 |

后续如需适配当地实际考试口令，应通过版本化配置扩充枚举，并在真机上校验发音；MVP 不开放任意文本播报。

## 4. 操作流程

### 路线准备

1. 在路线录制或路线详情中选择“标记考核项目”。
2. 选择预设项目，设置 20–200 米触发半径。
3. 地图显示独立的橙色扬声器标记。
4. 可单独编辑、删除和调整考核项目顺序。
5. 只有点击“保存”才新增项目；取消编辑不得残留默认考核项目。

### 模拟考试

1. 在训练准备页切换到“模拟考试播报”。
2. 路线没有考核项目时禁止开始，并给出明确提示。
3. 开始后持续记录训练轨迹，但不播放“训练开始”等状态语音。
4. 定位精度合格且进入当前考核项目半径时，播放固定项目口令，并自动推进到下一个项目。
5. 暂停时停止触发；继续后保持当前项目进度。
6. 用户主动结束或项目全部完成时，不额外播放非项目语音。

## 5. 触发规则

`ExamAnnouncementEngine` 按 `order` 严格顺序处理，只检查当前待播报项目：

```text
有效 GPS 点
  → 当前项目是否存在
  → 水平精度是否不超过 65 米
  → 与上次播报是否间隔至少 5 秒
  → 是否进入项目触发半径
  → 产生一次播报事件并将索引 +1
```

- 默认触发半径为 80 米，最小值为 20 米。
- 每个项目在一次训练中最多自动播报一次。
- 即使后续项目地理位置更近，也必须先触发当前项目，防止 GPS 漂移造成乱序。
- 5 秒最小间隔用于避免密集点位的语音重叠。
- 精度差于 65 米的定位点不触发，降低漂移误播风险。

## 6. 语音输出白名单

模拟考试模式唯一允许调用扬声器的入口是考核项目事件，输出值必须来自 `ExamProjectType.announcementText`。以下内容均不得送入语音合成器：

- 训练提示点标题与操作口诀；
- 路线名称、距离和进度；
- 开始、暂停、继续、结束等界面状态；
- 定位精度告警或错误提示；
- Watch 连接状态。

界面仍可显示必要状态，限制只针对语音输出。Apple Watch 接收相同的项目口令并给出触觉提醒。

## 7. 安全与异常处理

- 驾驶中不要求点击“完成/困难/跳过”，考核项目触发后自动推进。
- 路线结束但仍有未触发项目时，不补播，避免一次性播放多条失去场景意义的口令。
- 用户切换路线或重新开始训练时重置播报索引。
- 旧版本路线 JSON 没有 `announcements` 字段时自动迁移为空数组，现有路线不会损坏。
- Apple 地图路线导入只替换轨迹，保留训练提示点和考核项目。
- 正式道路验收必须由副驾操作手机；首次触发验证优先步行完成。

## 8. 验收标准

1. 两类点可独立创建、保存、编辑、排序和删除。
2. 取消新增考核项目后，路线数据和计数保持不变。
3. 训练提示模式只使用训练提示引擎；模拟考试模式只使用考核项目引擎。
4. 模拟考试开始、暂停、继续、结束时均无状态语音。
5. 进入范围后按顺序、每项一次播放固定考试口令。
6. 定位精度不合格、未进入半径或暂停期间不播放。
7. 路线保存重启后数据不丢失；旧路线正常读取。
8. Apple 地图导入后两类点均保留。
9. 自动化测试、iOS 模拟器构建和真机音频验收均通过。
